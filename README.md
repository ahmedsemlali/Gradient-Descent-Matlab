# Gradient Descent MATLAB

A simple MATLAB implementation of the Gradient Descent algorithm for finding the minimum of multivariable functions.

The project uses MATLAB's Symbolic Math Toolbox to calculate the gradient and iteratively update the variables until the gradient reaches the defined tolerance.

## Example

The project includes an example using:

f(x,y) = x^4 + y^2 - 25

Starting from an initial point, Gradient Descent iteratively moves toward the function's minimum and plots the result.
